### ✨ Key Modules & Features:
- **Offline PDF Suite:** AES-128/256 password protection, unlock, smart compression, merge, split, rotate, reorder, watermark, and local Hindi/English OCR (`Tesseract.js`).
- **Multimodal AI+ Assistant:** Reads up to **4 files simultaneously** (PDF, Word `.docx`, Excel `.xlsx/.csv`, Images), supports Hindi Voice Typing (`🎤 बोलें`), Read Aloud (`🔊 सुनें`), 1-click **Excel (`.xlsx`)** export, **Official Letterhead Word (`.doc`)** export, and HD Image/Poster generation.
- **Same-Format Visual Translator:** Translates English images, PDFs, and Word files into Hindi while preserving original layout and tables.
- **Exam Photo Resizer, Typing Test & Calculators:** Exact KB/DPI resizing, RSSB/SSC typing practice, Excel/CSV editor, and GST/TDS/Age/Number-to-Words tools.
- **Installable PWA:** Works offline after installation on Desktop (Windows/Mac) and Mobile (Android/iOS).
